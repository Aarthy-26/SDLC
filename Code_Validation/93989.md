## Issues Found

1. **Sensitive data exposure via exception payload retention and messages**
   - **Severity**: High
   - **Location**: `ClaudeApiClient.ensure2xx(...)` and `ClaudeApiException` (stores full `responseBody` and includes truncated payload in exception message)
   - **Risk**: API responses may include request echoes, IDs, or other sensitive data. Exception messages are frequently logged; storing raw response bodies increases accidental leakage.
   - **Remediation**:
     - Do **not** store raw body by default. Store only: HTTP status, operation, and a **sanitized** error code/message.
     - If needed for debugging, gate full body capture behind an explicit `DEBUG` flag and **redact** secrets/PII.
     - Avoid embedding body fragments in exception messages; log a correlation ID instead.

2. **Insufficient URL path encoding / input validation for `agentId`**
   - **Severity**: Medium
   - **Location**: `ClaudeApiClient.urlPathEscape(String)`
   - **Risk**: Only `/` and `\\` are replaced; reserved characters (e.g., `?`, `#`, `%`, `;`) and control characters are not safely encoded. This can cause incorrect routing or injection into paths.
   - **Remediation**:
     - Validate `agentId` against a strict allowlist pattern (e.g., UUID, base64url): `^[A-Za-z0-9_-]{1,128}$`.
     - Use a robust percent-encoding approach for path segments (build URI from components rather than string concatenation).

3. **No explicit HTTPS/TLS enforcement**
   - **Severity**: Medium
   - **Location**: `ClaudeApiClientConfig.fromEnv()` / usage of `baseUri`
   - **Risk**: Misconfiguration could allow `http://...` base URL, weakening transmission security.
   - **Remediation**:
     - Reject non-HTTPS schemes by default:
       - allow HTTP only when an explicit `ALLOW_INSECURE_HTTP=true` is set for non-prod.
     - Document certificate validation expectations; do not disable hostname verification.

4. **No maximum payload/response size controls (DoS/memory pressure risk)**
   - **Severity**: Medium
   - **Location**: `ClaudeApiClient.send(...)` uses `BodyHandlers.ofString()`
   - **Risk**: Large responses (e.g., base64 BIM content) can cause high memory usage.
   - **Remediation**:
     - Use streaming handlers (`BodyHandlers.ofInputStream()`) with explicit maximum size enforcement.
     - Add application-level size limits (max output bytes/base64 size) and fail safely.

5. **Lack of structured logging and audit events**
   - **Severity**: Medium
   - **Location**: `App.main` uses `System.out.println`
   - **Risk**: Limited traceability and operational audit readiness (SOC2).
   - **Remediation**:
     - Add SLF4J logging with structured fields.
     - Emit audit events for agent create/run/validate with a run/session ID.
     - Ensure logs redact secrets (API key, auth headers) and do not log raw outputs unless required.

6. **No retry/backoff or rate-limit handling**
   - **Severity**: Medium
   - **Location**: `ClaudeApiClient.send(...)`
   - **Risk**: Transient failures reduce availability; can violate resilience expectations.
   - **Remediation**:
     - Add bounded retries with exponential backoff for 429/5xx/timeouts.
     - Respect `Retry-After` headers.
     - Consider idempotency keys for agent creation/runs if supported.

7. **Output model is weakly typed; validation is minimal**
   - **Severity**: Low
   - **Location**: `AgentRunResponse.output` is `Object`; validators only check non-null and basic non-empty
   - **Risk**: Contract drift undetected; runtime casting issues; reduced correctness.
   - **Remediation**:
     - Define explicit DTOs for BIM and Layout outputs and validate required fields:
       - BIM: `fileName`, `contentType`, `contentBase64` (validate base64), `summary`
       - Layout: `layoutId`, `version`, `fields[]`, `summary`
     - Add allowlists for `contentType` and size limits.

8. **Build pipeline gaps: missing security/static analysis tooling**
   - **Severity**: Medium
   - **Location**: `pom.xml`
   - **Risk**: No automated dependency vulnerability scans or code quality gates.
   - **Remediation**:
     - Add at minimum:
       - `maven-enforcer-plugin` (Java version, dependency convergence)
       - OWASP `dependency-check-maven`
       - SpotBugs/PMD/Checkstyle
       - Optional: CycloneDX SBOM generation
