1. **B-Injection:** ✅ No SQL/OS/LDAP injection patterns

2. **B-BrokenAuthentication:** ✅ No hardcoded credentials or session/token logic observed

3. **B-SensitiveDataExposure:** ❌ **Finding present**
   - **Severity:** High
   - **Location:** `DataSourceHealthController.health()` response includes `jdbcUrl` and `user` (and product/version)
   - **Criterion:** B-SensitiveDataExposure
   - **Risk:** Exposes infrastructure and potentially sensitive identifiers that can aid attackers (database hostnames, usernames).
   - **Remediation:**
     - Return only minimal `status` + `timestamp`.
     - If details are required, restrict endpoint access (Spring Security roles, management port/network ACLs) and mask/redact sensitive values.

   - **Remediation:**
