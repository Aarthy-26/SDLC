### C. Code Quality & Maintainability

**Status:** _Partially compliant_

1. **Null-safety bug: NPE risk in normalization**
   - **Severity:** High
   - **Location:** `NormalizationPipeline.normalizeOperations(...)` uses `operation.value().map(...)`
   - **Criterion:** C-NullSafety
   - **Details:** Although `Operation` compact constructor normalizes null `Optional` to `Optional.empty()`, the normalizer calls `operation.value()` on the *incoming* `Operation`. If an instance exists with `value == null` (possible via reflection/deserialization/malformed construction), `operation.value()` returns null and NPE occurs.
   - **Remediation:** Defensively normalize before mapping:
     ```java
     Optional<String> safeValue = Optional.ofNullable(operation.value()).orElse(Optional.empty());
     normalized.add(new Operation(operation.type(), trimToEmpty(operation.target()), safeValue.map(StringNormalizer::trimToEmpty)));
     ```
