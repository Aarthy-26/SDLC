## 3) Issues Found (Severity, Location, Criterion, Remediation)

2. User/session and parameters null-safety gaps in Router API
- **Severity:** Medium
- **Location:** `Router.clickNavigateButton(...)`, `Router.openByUrl(...)`, `Router.backOrClose(...)`

- **Severity:** Medium
- **Location:** `AppConfig.addPage(Page page)`
- **Criterion:** **C-NullSafety**

7. Hard-coded event/message strings (magic strings)
