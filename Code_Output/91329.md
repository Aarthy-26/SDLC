User Story ID: 91329

1. **Requirement Summary** — the clarified, confirmed requirement

Build a secure, maintainable Java-based “core” service that a VS Code plugin can call to:
- Load an existing JSON-based “app” definition from disk.
- Accept natural-language user requirements (NLP input) and produce a deterministic “change plan” (JSON Patch operations) describing modifications to the JSON app.
- Apply those changes to the JSON app safely (atomic write, backup), validate resulting JSON for correctness, and return the updated app JSON.
- Package the updated app as an artifact (ZIP) suitable for upload to DataPowerAI (stubbed as a deployable bundle generator).

**Assumptions** (used to proceed without blocking):
- The “JSON app” is a single JSON file on disk (default `app.json`).
- The VS Code plugin communicates with this Java service over a local HTTP API.
- NLP is implemented using a rules-based interpreter (keyword/regex) to identify requested changes. This satisfies “NLP can understand” at MVP level without external LLM dependencies.
- Code changes are expressed and applied using RFC 6902 JSON Patch.
- Validation includes: JSON parse validity + required top-level fields `name` and `version` (if missing, they are added).
- Deployment to DataPowerAI is represented as generating a ZIP bundle containing the updated JSON and a manifest; actual upload is environment-specific and not specified.
- Authentication: local token-based header (`X-API-KEY`) using an environment variable `AAVA_API_KEY`.

package com.ascendion.aava.jsonapp.api;

import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;

import java.io.IOException;
import java.nio.charset.StandardCharsets;

/**
 * Simple API key authentication for local plugin -> service calls.
 *
 * Expected header: X-API-KEY
 * Expected value: environment variable AAVA_API_KEY
 */
@Component
public class ApiKeyFilter extends OncePerRequestFilter {

    private static final String HEADER = "X-API-KEY";

    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain filterChain)
            throws ServletException, IOException {

        // Allow health checks without auth.
        if (request.getRequestURI() != null && request.getRequestURI().endsWith("/health")) {
            filterChain.doFilter(request, response);
            return;
        }

        String expected = System.getenv("AAVA_API_KEY");
        if (expected == null || expected.isBlank()) {
            response.setStatus(HttpStatus.SERVICE_UNAVAILABLE.value());
            response.setContentType("application/json");
            response.getOutputStream().write(
                    ("{\"error\":\"Server not configured: missing AAVA_API_KEY env var\"}")
                            .getBytes(StandardCharsets.UTF_8));
            return;
        }

        String provided = request.getHeader(HEADER);
        if (provided == null || !constantTimeEquals(expected, provided)) {
            response.setStatus(HttpStatus.UNAUTHORIZED.value());
            response.setContentType("application/json");
            response.getOutputStream().write(
                    ("{\"error\":\"Unauthorized\"}").getBytes(StandardCharsets.UTF_8));
            return;
        }

        filterChain.doFilter(request, response);
    }

    private boolean constantTimeEquals(String a, String b) {
        if (a == null || b == null) {
            return false;
        }
        byte[] ba = a.getBytes(StandardCharsets.UTF_8);
        byte[] bb = b.getBytes(StandardCharsets.UTF_8);
        int diff = ba.length ^ bb.length;
        int max = Math.max(ba.length, bb.length);
        for (int i = 0; i < max; i++) {
            byte xa = i < ba.length ? ba[i] : 0;
            byte xb = i < bb.length ? bb[i] : 0;
            diff |= (xa ^ xb);
        }
        return diff == 0;
    }
}

// File: src/main/java/com/ascendion/aava/jsonapp/service/AppEnhancementService.java
package com.ascendion.aava.jsonapp.service;

import com.ascendion.aava.jsonapp.model.ApplyChangesRequest;
import com.ascendion.aava.jsonapp.model.ApplyChangesResponse;
import com.ascendion.aava.jsonapp.model.GeneratePlanRequest;
import com.ascendion.aava.jsonapp.model.GeneratePlanResponse;
import com.fasterxml.jackson.core.JsonProcessingException;
import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.fasterxml.jackson.databind.node.ArrayNode;
import com.fasterxml.jackson.databind.node.ObjectNode;
import com.github.fge.jsonpatch.JsonPatch;
import com.github.fge.jsonpatch.JsonPatchException;
import org.springframework.stereotype.Service;

import java.io.IOException;
import java.io.InputStream;
import java.nio.file.*;
import java.time.Instant;
import java.util.Locale;
import java.util.zip.ZipEntry;
import java.util.zip.ZipOutputStream;

/**
 * Core service: read/validate JSON app, generate plan from NL requirements, apply patch, and package artifact.
 */
@Service
public class AppEnhancementService {

    private final ObjectMapper mapper;

    public AppEnhancementService(ObjectMapper mapper) {
        this.mapper = mapper;
    }

    public GeneratePlanResponse generatePlan(GeneratePlanRequest request) {
        Path appPath = validatedPath(request.appPath());
        JsonNode current = readJson(appPath);

        // Ensure minimum structure.
        ObjectNode normalized = normalizeApp(current);

        ArrayNode patchOps = mapper.createArrayNode();
        String summary = interpretRequirementToPatch(request.requirementText(), normalized, patchOps);

        ObjectNode patchWrapper = mapper.createObjectNode();
        patchWrapper.set("ops", patchOps);

        // For compatibility with common JSON Patch libs, return the operations array itself.
        return new GeneratePlanResponse(appPath.toString(), patchOps, summary);
    }

    public ApplyChangesResponse applyChanges(ApplyChangesRequest request) {
        Path appPath = validatedPath(request.appPath());
        JsonNode current = readJson(appPath);
        ObjectNode normalized = normalizeApp(current);

        JsonPatch patch = toPatch(request.patch());

        JsonNode updated;
        try {
            updated = patch.apply(normalized);
        } catch (JsonPatchException e) {
            throw new AppValidationException("Patch could not be applied: " + safeMsg(e.getMessage()));
        }

        ObjectNode updatedNormalized = normalizeApp(updated);
        validateApp(updatedNormalized);

        String backupPath = backupAndAtomicWrite(appPath, updatedNormalized, request.backupDir());

        return new ApplyChangesResponse(appPath.toString(), backupPath, updatedNormalized, "OK");
    }

    public PackageResult packageForDeployment(String appPathStr, String outputZipStr) {
        String effectiveAppPath = (appPathStr == null || appPathStr.isBlank()) ? "app.json" : appPathStr;
        Path appPath = validatedPath(effectiveAppPath);
        JsonNode current = readJson(appPath);
        ObjectNode normalized = normalizeApp(current);
        validateApp(normalized);

        Path outputZip = (outputZipStr == null || outputZipStr.isBlank())
                ? Paths.get("datapowerai-bundle.zip")
                : Paths.get(outputZipStr);

        try {
            if (outputZip.getParent() != null) {
                Files.createDirectories(outputZip.getParent());
            }
            long bytes = writeBundleZip(outputZip, normalized);
            return new PackageResult(outputZip.toAbsolutePath().toString(), bytes);
        } catch (IOException e) {
            throw new IllegalArgumentException("Failed to create bundle ZIP: " + safeMsg(e.getMessage()));
        }
    }

    private long writeBundleZip(Path zipPath, ObjectNode appJson) throws IOException {
        byte[] appBytes = mapper.writerWithDefaultPrettyPrinter().writeValueAsBytes(appJson);
        ObjectNode manifest = mapper.createObjectNode();
        manifest.put("generatedAt", Instant.now().toString());
        manifest.put("artifactType", "DataPowerAI-JSON-App-Bundle");
        manifest.put("appName", appJson.path("name").asText("unknown"));
        manifest.put("appVersion", appJson.path("version").asText("0.0.0"));
        byte[] manifestBytes = mapper.writerWithDefaultPrettyPrinter().writeValueAsBytes(manifest);

        long written = 0;
        try (ZipOutputStream zos = new ZipOutputStream(Files.newOutputStream(zipPath, StandardOpenOption.CREATE, StandardOpenOption.TRUNCATE_EXISTING))) {
            ZipEntry appEntry = new ZipEntry("app.json");
            zos.putNextEntry(appEntry);
            zos.write(appBytes);
            zos.closeEntry();
            written += appBytes.length;

            ZipEntry manifestEntry = new ZipEntry("manifest.json");
            zos.putNextEntry(manifestEntry);
            zos.write(manifestBytes);
            zos.closeEntry();
            written += manifestBytes.length;
        }
        return written;
    }

    private String interpretRequirementToPatch(String requirementText, ObjectNode currentApp, ArrayNode patchOps) {
        String text = requirementText == null ? "" : requirementText.trim();
        if (text.isEmpty()) {
            throw new IllegalArgumentException("requirementText must not be empty");
        }

        String lowered = text.toLowerCase(Locale.ROOT);
        StringBuilder summary = new StringBuilder("Interpreted requirement into patch operations: ");

        boolean changed = false;

        // 1) Rename app: "rename app to X" / "set name to X"
        String newName = RegexUtil.firstGroup(lowered, "(?:rename\\s+app\\s+to|set\\s+name\\s+to)\\s+([a-z0-9 _-]{2,64})");
        if (newName != null) {
            String trimmed = newName.trim();
            patchOps.add(op("replace", "/name", trimmed));
            summary.append("set name='" + trimmed + "'; ");
            changed = true;
        }

        // 2) Set version: "set version to 1.2.3"
        String version = RegexUtil.firstGroup(lowered, "set\\s+version\\s+to\\s+([0-9]+\\.[0-9]+\\.[0-9]+)");
        if (version != null) {
            patchOps.add(op("replace", "/version", version));
            summary.append("set version='" + version + "'; ");
            changed = true;
        }

        // 3) Add UI field: "add field <id> label <label>"
        // Assumption: UI schema is at /ui/fields (array). If absent, we create it.
        String fieldId = RegexUtil.firstGroup(text, "(?i)add\\s+field\\s+([A-Za-z][A-Za-z0-9_-]{1,32})");
        String fieldLabel = RegexUtil.firstGroup(text, "(?i)label\\s+\"([^\"]{1,64})\"");
        if (fieldId != null) {
            ensureUiFieldsExist(currentApp, patchOps);
            ObjectNode field = mapper.createObjectNode();
            field.put("id", fieldId);
            field.put("type", "text");
            field.put("label", (fieldLabel == null || fieldLabel.isBlank()) ? fieldId : fieldLabel);
            patchOps.add(op("add", "/ui/fields/-", field));
            summary.append("add ui field id='" + fieldId + "'; ");
            changed = true;
        }

        // 4) Enable feature flag: "enable feature X"
        String feature = RegexUtil.firstGroup(lowered, "enable\\s+feature\\s+([a-z0-9_-]{2,32})");
        if (feature != null) {
            ensureObjectExists(currentApp, patchOps, "/features");
            patchOps.add(op("add", "/features/" + JsonPointerEscaper.escape(feature), true));
            summary.append("enable feature '" + feature + "'; ");
            changed = true;
        }

        // 5) Disable feature: "disable feature X"
        String disable = RegexUtil.firstGroup(lowered, "disable\\s+feature\\s+([a-z0-9_-]{2,32})");
        if (disable != null) {
            ensureObjectExists(currentApp, patchOps, "/features");
            patchOps.add(op("add", "/features/" + JsonPointerEscaper.escape(disable), false));
            summary.append("disable feature '" + disable + "'; ");
            changed = true;
        }

        if (!changed) {
            // Safety: If we can't interpret, we do not guess changes.
            summary.append("no recognized operations (no changes generated)");
        }

        return summary.toString().trim();
    }

    private void ensureUiFieldsExist(ObjectNode currentApp, ArrayNode patchOps) {
        if (!currentApp.has("ui") || !currentApp.get("ui").isObject()) {
            patchOps.add(op("add", "/ui", mapper.createObjectNode()));
        }
        JsonNode ui = currentApp.path("ui");
        if (!ui.has("fields") || !ui.get("fields").isArray()) {
            patchOps.add(op("add", "/ui/fields", mapper.createArrayNode()));
        }
    }

    private void ensureObjectExists(ObjectNode currentApp, ArrayNode patchOps, String jsonPointer) {
        // Only supports creating a top-level object at /key for MVP.
        if (jsonPointer == null || !jsonPointer.startsWith("/") || jsonPointer.indexOf('/', 1) != -1) {
            throw new IllegalArgumentException("Unsupported path for ensureObjectExists: " + jsonPointer);
        }
        String key = jsonPointer.substring(1);
        if (!currentApp.has(key) || !currentApp.get(key).isObject()) {
            patchOps.add(op("add", jsonPointer, mapper.createObjectNode()));
        }
    }

    private ObjectNode op(String operation, String path, Object value) {
        ObjectNode node = mapper.createObjectNode();
        node.put("op", operation);
        node.put("path", path);
        if (!"remove".equals(operation)) {
            node.set("value", mapper.valueToTree(value));
        }
        return node;
    }

    private JsonPatch toPatch(JsonNode patchNode) {
        if (patchNode == null || !patchNode.isArray()) {
            throw new IllegalArgumentException("patch must be a JSON array of RFC6902 operations");
        }
        try {
            return JsonPatch.fromJson(patchNode);
        } catch (JsonPatchException e) {
            throw new IllegalArgumentException("Invalid patch: " + safeMsg(e.getMessage()));
        }
    }

    private ObjectNode normalizeApp(JsonNode node) {
        ObjectNode obj;
        if (node != null && node.isObject()) {
            obj = (ObjectNode) node;
        } else {
            obj = mapper.createObjectNode();
        }
        if (!obj.hasNonNull("name") || obj.get("name").asText().isBlank()) {
            obj.put("name", "unnamed-app");
        }
        if (!obj.hasNonNull("version") || obj.get("version").asText().isBlank()) {
            obj.put("version", "0.0.1");
        }
        if (!obj.has("ui") || !obj.get("ui").isObject()) {
            obj.set("ui", mapper.createObjectNode());
        }
        if (!obj.path("ui").has("fields") || !obj.path("ui").get("fields").isArray()) {
            ((ObjectNode) obj.get("ui")).set("fields", mapper.createArrayNode());
        }
        if (!obj.has("features") || !obj.get("features").isObject()) {
            obj.set("features", mapper.createObjectNode());
        }
        return obj;
    }

    private void validateApp(ObjectNode app) {
        String name = app.path("name").asText("").trim();
        String version = app.path("version").asText("").trim();
        if (name.isEmpty()) {
            throw new AppValidationException("App 'name' must be present");
        }
        if (!version.matches("\\d+\\.\\d+\\.\\d+")) {
            throw new AppValidationException("App 'version' must be in semantic version format X.Y.Z");
        }
        if (!app.path("ui").isObject() || !app.path("ui").path("fields").isArray()) {
            throw new AppValidationException("App 'ui.fields' must be an array");
        }
        if (!app.path("features").isObject()) {
            throw new AppValidationException("App 'features' must be an object");
        }
    }

    private String backupAndAtomicWrite(Path appPath, ObjectNode updated, String backupDir) {
        try {
            Path parent = appPath.toAbsolutePath().getParent();
            if (parent == null) {
                parent = Paths.get(".").toAbsolutePath().normalize();
            }

            Path backupBase = (backupDir == null || backupDir.isBlank())
                    ? parent.resolve(".backup")
                    : Paths.get(backupDir);

            Files.createDirectories(backupBase);

            String backupFileName = appPath.getFileName().toString() + "." + Instant.now().toEpochMilli() + ".bak";
            Path backupPath = backupBase.resolve(backupFileName);

            // Backup original if exists.
            if (Files.exists(appPath)) {
                Files.copy(appPath, backupPath, StandardCopyOption.COPY_ATTRIBUTES);
            } else {
                // If the app doesn't exist, we consider it a not-found error to avoid accidental creation.
                throw new NotFoundException("App JSON not found at: " + appPath);
            }

            byte[] bytes = mapper.writerWithDefaultPrettyPrinter().writeValueAsBytes(updated);

            Path tmp = Files.createTempFile(parent, "app", ".json.tmp");
            Files.write(tmp, bytes, StandardOpenOption.TRUNCATE_EXISTING);

            try {
                Files.move(tmp, appPath, StandardCopyOption.REPLACE_EXISTING, StandardCopyOption.ATOMIC_MOVE);
            } catch (AtomicMoveNotSupportedException e) {
                Files.move(tmp, appPath, StandardCopyOption.REPLACE_EXISTING);
            }

            return backupPath.toAbsolutePath().toString();
        } catch (JsonProcessingException e) {
            throw new AppValidationException("Failed to serialize updated JSON: " + safeMsg(e.getMessage()));
        } catch (IOException e) {
            throw new IllegalArgumentException("Failed to write updated app: " + safeMsg(e.getMessage()));
        }
    }

    private Path validatedPath(String p) {
        if (p == null || p.isBlank()) {
            throw new IllegalArgumentException("appPath is required");
        }
        Path path = Paths.get(p).normalize();
        // Minimal path safety: block attempts to reference directories like .. in a suspicious way.
        // Note: normalization resolves .., so we enforce not ending up as root.
        if (path.toString().contains("..")) {
            throw new IllegalArgumentException("Invalid appPath");
        }
        return path;
    }

    private JsonNode readJson(Path appPath) {
        if (!Files.exists(appPath)) {
            throw new NotFoundException("App JSON not found at: " + appPath.toAbsolutePath());
        }
        try (InputStream in = Files.newInputStream(appPath, StandardOpenOption.READ)) {
            return mapper.readTree(in);
        } catch (IOException e) {
            throw new AppValidationException("Invalid JSON or unreadable file: " + safeMsg(e.getMessage()));
        }
    }

    private String safeMsg(String msg) {
        if (msg == null) {
            return "";
        }
        // Prevent log/response injection and overly verbose error messages.
        return msg.replaceAll("[\r\n\t]", " ").trim();
    }

    /** Result of packaging operation. */
    public record PackageResult(String bundlePath, long bytesWritten) { }
}

/**
 * Safe regex helper utilities.
 */
public final class RegexUtil {

    private RegexUtil() {
    }

    /**
     * Returns first capture group match or null.
     */
    public static String firstGroup(String input, String pattern) {
        if (input == null || pattern == null) {
            return null;
        }
        Pattern p = Pattern.compile(pattern);
        Matcher m = p.matcher(input);
        if (m.find() && m.groupCount() >= 1) {
            return m.group(1);
        }
        return null;
    }
}

3. **Code Documentation** — classes/methods/logic explanation + dependencies

- `JsonAppEnhancerApplication`: Spring Boot bootstrap.
- `ApiKeyFilter`: Enforces token auth for all endpoints except `/health` using `X-API-KEY` compared in constant time against env var `AAVA_API_KEY` (no hardcoded secrets).
- `AppController`: Plugin-facing REST endpoints:
  - `POST /api/v1/app/plan`: Accepts `appPath` + `requirementText`, returns JSON Patch ops array.
  - `POST /api/v1/app/apply`: Accepts `appPath` + patch ops array, applies patch, validates, backs up original, writes updated JSON atomically.
  - `POST /api/v1/app/package`: Produces a deployable ZIP bundle containing `app.json` and `manifest.json`.
- `AppEnhancementService`:
  - `generatePlan(...)`: Reads current JSON, normalizes structure, interprets NL requirement via safe regex rules into JSON Patch.
  - `applyChanges(...)`: Converts patch to `JsonPatch`, applies, validates, and persists safely.
  - `packageForDeployment(...)`: Creates a ZIP bundle artifact.
- `GlobalExceptionHandler`: Converts typed exceptions into appropriate HTTP status codes and safe messages.
- `RegexUtil`, `JsonPointerEscaper`: Helpers for safe parsing and pointer escaping.
