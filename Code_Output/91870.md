1. **Requirement Summary** — the clarified, confirmed requirement

Create a Java-based “requirement-to-code generation and review” utility that:
- Accepts a user-provided plain-language requirement from standard input.
- Generates Java code that implements the requirement (for this user story, the generator produces a deterministic example implementation: a standalone calculator that adds two numbers).
- Passes the generated Java code to a dedicated review component (review agent) that evaluates compilation sanity, basic static checks (dangerous patterns), and requirement alignment heuristics.
- Outputs both the generated Java code and the review results.

**Assumptions**:
- Single-file, framework-free implementation is acceptable (no Spring Boot) and must compile/run via `javac`/`java`.
- “Dedicated review agent” is implemented as a separate in-process component/class (not an external LLM).
- Requirement alignment is performed via lightweight heuristics (keyword overlap + required capability checks) since full semantic verification is out of scope without external tooling.
- No secrets are embedded; no PII is included.

/**
 * RequirementToJavaCodeAgent
 *
 * <p>A standalone utility that demonstrates an “agent” pipeline:
 * (1) Intake a plain-language requirement.
 * (2) Generate Java code for the requirement.
 * (3) Pass generated code to a separate ReviewAgent.
 * (4) Print both the generated code and review results.
 *
 * <p>Compile:
 *   javac -d out RequirementToJavaCodeAgent.java
 * Run:
 *   java -cp out com.example.requirementagent.RequirementToJavaCodeAgent

public final class RequirementToJavaCodeAgent {

    public static void main(String[] args) throws IOException {
        String requirement = readAllStdIn();
        if (requirement == null || requirement.trim().isEmpty()) {
            System.err.println("Error: requirement input is empty.");
            System.err.println("Provide a plain-language requirement via stdin.");
            System.exit(2);
            return;
        }

        CodeGenerator generator = new DeterministicExampleCodeGenerator();
        GeneratedArtifact artifact = generator.generate(requirement);

        ReviewAgent reviewer = new BasicReviewAgent();
        ReviewReport report = reviewer.review(requirement, artifact);

        System.out.println("=== Requirement ===");
        System.out.println(requirement.trim());
        System.out.println();

        System.out.println("=== Generated Java Code (" + artifact.getPrimaryClassName() + ") ===");
        System.out.println(artifact.getSourceCode());
        System.out.println();

        System.out.println("=== Review Results ===");
        System.out.println(report.toPrettyString());

        if (!report.isPass()) {
            System.exit(1);
        }
    }

    private static String readAllStdIn() throws IOException {
        ByteArrayOutputStream baos = new ByteArrayOutputStream();
        byte[] buf = new byte[4096];
        int r;
        while ((r = System.in.read(buf)) != -1) {
            baos.write(buf, 0, r);
        }
        return baos.toString(StandardCharsets.UTF_8);
    }

            StringBuilder sb = new StringBuilder();
            sb.append("PASS: ").append(pass).append('\n');
            sb.append("Findings:");
            if (findings.isEmpty()) {
                sb.append(" none\n");
            } else {
                sb.append('\n');
                for (int i = 0; i < findings.size(); i++) {
                    sb.append("  ").append(i + 1).append(") ").append(findings.get(i)).append('\n');
                }

            sb.append("Suggestions:");

    /**
     * A basic in-process review agent that performs:
     * - In-memory compilation
     * - Static pattern checks for risky constructs
     * - Simple requirement alignment heuristics
     */
    public static final class BasicReviewAgent implements ReviewAgent {

        private static final Set<Pattern> DANGEROUS_PATTERNS = new HashSet<>(Arrays.asList(
                Pattern.compile("\\bRuntime\\.getRuntime\\(\\)\\.exec\\b"),
                Pattern.compile("\\bProcessBuilder\\b"),
                Pattern.compile("\\bSystem\\.setProperty\\b"),
                Pattern.compile("\\bFiles\\.delete\\b"),
                Pattern.compile("\\bDELETE\\s+FROM\\b", Pattern.CASE_INSENSITIVE),
                Pattern.compile("\\bDROP\\s+TABLE\\b", Pattern.CASE_INSENSITIVE)
        ));

        @Override
        public ReviewReport review(String requirement, GeneratedArtifact artifact) {
            Objects.requireNonNull(requirement, "requirement");
            Objects.requireNonNull(artifact, "artifact");

            List<String> findings = new ArrayList<>();
            List<String> suggestions = new ArrayList<>();

            // 1) Compile check
            CompilationResult compilation = compileInMemory(artifact.getPrimaryClassName(), artifact.getSourceCode());
            if (!compilation.success) {
                findings.add("Compilation failed.");
                findings.addAll(compilation.diagnostics);
                suggestions.add("Fix compilation errors and re-run review.");
            } else {
                findings.add("Compilation succeeded.");
            }

            // 2) Dangerous pattern scan
            List<String> patternHits = scanForDangerousPatterns(artifact.getSourceCode());
            if (!patternHits.isEmpty()) {
                findings.add("Potentially dangerous patterns found: " + patternHits);
                suggestions.add("Remove/guard dangerous operations (command execution, destructive IO/SQL)." );
            } else {
                findings.add("No dangerous patterns detected by heuristic scan.");
            }

            // 3) Requirement alignment heuristic
            AlignmentResult alignment = checkAlignment(requirement, artifact.getSourceCode());
            findings.add("Alignment score (0-100): " + alignment.score);
            if (!alignment.notes.isEmpty()) {
                findings.addAll(alignment.notes);
            }
            if (alignment.score < 50) {
                suggestions.add("Generated code appears weakly aligned with requirement; adjust generator logic/templates.");
            }

            boolean pass = compilation.success && patternHits.isEmpty() && alignment.score >= 50;
            if (!pass && suggestions.isEmpty()) {
                suggestions.add("Review failed; address findings and regenerate.");
            }

            return new ReviewReport(pass, findings, suggestions);
        }

        private static final class AlignmentResult {
            final int score;
            final List<String> notes;

            AlignmentResult(int score, List<String> notes) {
                this.score = score;
                this.notes = notes;
            }
        }

        private AlignmentResult checkAlignment(String requirement, String source) {
            String req = normalize(requirement);
            String src = normalize(source);

            // Keyword overlap scoring (simple, deterministic)
            Set<String> reqTokens = tokenize(req);
            Set<String> srcTokens = tokenize(src);

            if (reqTokens.isEmpty()) {
                return new AlignmentResult(0, Collections.singletonList("Requirement tokens are empty after normalization."));
            }

            int common = 0;
            for (String t : reqTokens) {
                if (srcTokens.contains(t)) {
                    common++;
                }
            }

            double overlap = (double) common / (double) reqTokens.size();
            int score = (int) Math.round(overlap * 100.0);

            List<String> notes = new ArrayList<>();
            notes.add("Common tokens: " + common + " / " + reqTokens.size());

            // Additional heuristic: ensure it is Java code with a class and main
            boolean hasClass = src.contains(" class ");
            boolean hasMain = src.contains("static void main");
            if (!hasClass) {
                notes.add("Heuristic: source does not contain a class declaration.");
                score = Math.max(0, score - 30);
            }
            if (!hasMain) {
                notes.add("Heuristic: source does not contain a main method.");
                score = Math.max(0, score - 30);
            }

            return new AlignmentResult(score, notes);
        }

        private String normalize(String s) {
            String lower = s.toLowerCase(Locale.ROOT);
            return lower.replaceAll("[^a-z0-9\\s]+", " ").replaceAll("\\s+", " ").trim();
        }

        private Set<String> tokenize(String s) {
            if (s == null || s.trim().isEmpty()) {
                return Collections.emptySet();
            }
            String[] parts = s.split(" ");
            Set<String> tokens = new HashSet<>();
            for (String p : parts) {
                if (p.length() >= 4) { // drop very short words to reduce noise
                    tokens.add(p);
                }
            }
            return tokens;
        }

        private List<String> scanForDangerousPatterns(String source) {
            if (source == null) {
                return Collections.singletonList("source is null");
            }
            List<String> hits = new ArrayList<>();
            for (Pattern p : DANGEROUS_PATTERNS) {
                Matcher m = p.matcher(source);
                if (m.find()) {
                    hits.add(p.pattern());
                }
            }
            return hits;
        }

        private static final class CompilationResult {
            final boolean success;
            final List<String> diagnostics;

            CompilationResult(boolean success, List<String> diagnostics) {
                this.success = success;
                this.diagnostics = diagnostics;
            }
        }

        private CompilationResult compileInMemory(String primaryClassName, String sourceCode) {
            JavaCompiler compiler = ToolProvider.getSystemJavaCompiler();
            if (compiler == null) {
                return new CompilationResult(false, Collections.singletonList(
                        "No system Java compiler available. Run with a JDK (not a JRE)."));
            }

            DiagnosticCollector<JavaFileObject> diagnostics = new DiagnosticCollector<>();

            // We attempt compilation as a single unit; package/class name inside the source must be valid.
            InMemoryJavaFileObject fileObject = new InMemoryJavaFileObject(primaryClassName, sourceCode);

            List<String> options = Arrays.asList("-Xlint:all", "-proc:none");
            StandardJavaFileManager fileManager = compiler.getStandardFileManager(diagnostics, Locale.ROOT, StandardCharsets.UTF_8);

            JavaCompiler.CompilationTask task = compiler.getTask(
                    null,
                    fileManager,
                    diagnostics,
                    options,
                    null,
                    Collections.singletonList(fileObject)
            );

            Boolean ok = task.call();
            try {
                fileManager.close();
            } catch (IOException ignored) {
                // Best effort close.
            }

            List<String> diagLines = new ArrayList<>();
            for (Diagnostic<? extends JavaFileObject> d : diagnostics.getDiagnostics()) {
                diagLines.add(formatDiagnostic(d));
            }

            return new CompilationResult(Boolean.TRUE.equals(ok), diagLines);
        }

        private String formatDiagnostic(Diagnostic<? extends JavaFileObject> d) {
            return d.getKind() + ": line " + d.getLineNumber() + ", col " + d.getColumnNumber() + " - " + d.getMessage(Locale.ROOT);
        }
    }

    /** Simple in-memory Java source file object used for compilation checks. */
    public static final class InMemoryJavaFileObject extends SimpleJavaFileObject {
        private final String code;

        public InMemoryJavaFileObject(String className, String code) {
            super(URI.create("string:///" + className.replace('.', '/') + JavaFileObject.Kind.SOURCE.extension),
                    JavaFileObject.Kind.SOURCE);
            this.code = Objects.requireNonNull(code, "code");
        }

        @Override
        public CharSequence getCharContent(boolean ignoreEncodingErrors) {
            return code;
        }

        @Override
        public OutputStream openOutputStream() {
            // Compilation output is not needed for this review; discard.
            return new ByteArrayOutputStream();
        }
    }

    /**
     * Audit entry for traceability.
     */
    public static final class AuditLog {
        private final LocalDate date;
        private final String requirement;
        private final String artifactClass;

        public AuditLog(LocalDate date, String requirement, String artifactClass) {
            this.date = Objects.requireNonNull(date, "date");
            this.requirement = Objects.requireNonNull(requirement, "requirement");
            this.artifactClass = Objects.requireNonNull(artifactClass, "artifactClass");
        }

        public String toLine() {
            return "Requirement received and code generated on " + date + " by agent. (artifact=" + artifactClass + ")";
        }

        public Map<String, String> toMap() {
            Map<String, String> m = new HashMap<>();
            m.put("date", date.toString());
            m.put("artifactClass", artifactClass);
            m.put("requirement", requirement);
            return m;
        }
    }
}

3. **Code Documentation** — classes/methods/logic explanation + dependencies

- `RequirementToJavaCodeAgent` (main): Reads the requirement from stdin, invokes the `CodeGenerator`, then passes output to `ReviewAgent`, and prints requirement, generated code, and review report. Exits non-zero on failed review.
- `DeterministicExampleCodeGenerator`: Implements `CodeGenerator`; produces a deterministic, compilable Java program (`GeneratedAdditionTool`) to demonstrate the pipeline.
- `BasicReviewAgent`: Separate review component that compiles the generated code in-memory using `javax.tools.JavaCompiler`, scans for risky patterns, and computes a simple alignment score based on keyword overlap plus presence of `class` and `main`.
- `ReviewReport`: Holds pass/fail, findings, and suggestions; renders in a readable format.
- `InMemoryJavaFileObject`: Utility for feeding source into the compiler.
- `AuditLog`: Simple traceability record (date, requirement, artifact class).

**Dependencies**:
- No external dependencies. Uses only standard JDK modules (`java.*` and `javax.tools.*`). Must be run with a JDK.
