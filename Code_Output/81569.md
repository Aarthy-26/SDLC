User Story ID: 81569

1. **Requirement Summary**

Implement a secure approval workflow for edits to existing “artifacts” such that edits are saved as draft versions and only become live after approval by an authorized approver (excluding the submitter). The workflow must preserve the existing live artifact until approval, increment version on approval while keeping artifact ID stable, and provide an immutable audit trail of all key actions. Approvers must acknowledge impact analysis before approve/reject is allowed; approve/reject requires mandatory comment. Impact analysis lists must exclude dependent artifacts that are in Draft/In Review and include only approved versions.

**Assumptions**
- Implemented as a Spring Boot 3 (Java 17) REST service with an in-memory H2 database for demonstration; swap to a real RDBMS by changing datasource config.
- Authentication is via a simple `X-User-Id` header for demo. Authorization is role-based using `X-User-Roles` header (comma-separated: `ARTIFACT_OWNER`, `LEVEL_ADMIN`, `SUPER_ADMIN`, `APPROVER`). In production, replace with OAuth2/JWT.
- “Impact analysis” is represented as a stored JSON string generated earlier and attached to the draft; approval requires an explicit acknowledgement API call before approve/reject.
- “Downstream consumers automatically reference the newly approved version” is modeled by keeping `artifact_id` stable and marking a single version as `LIVE`.
- Audit log is append-only at application level (no update/delete endpoints; repository does not expose delete). DB-level immutability is recommended via permissions/triggers but not shown in this demo.

import java.util.Collections;
import java.util.Objects;

/**
 * Simple authenticated principal derived from request headers.
 *
 * <p>Production systems should use OAuth2/JWT with Spring Security; this is a lightweight demo.</p>
 */
public final class RequestUser {
    private final String userId;
    private final Set<String> roles;

    public RequestUser(String userId, Set<String> roles) {
        this.userId = Objects.requireNonNull(userId, "userId");
        this.roles = Collections.unmodifiableSet(Objects.requireNonNull(roles, "roles"));
    }

    public String userId() {
        return userId;
    }

    public Set<String> roles() {
        return roles;
    }

    public boolean hasRole(String role) {
        return roles.contains(role);
    }
}

package com.ascendion.aava.workflow.security;

import org.springframework.stereotype.Component;

import java.util.Arrays;
import java.util.Set;
import java.util.stream.Collectors;

/**
 * Resolves {@link RequestUser} from request headers.
 */
@Component
public class UserContextResolver {

    public RequestUser fromHeaders(String userIdHeader, String rolesHeader) {
        String userId = (userIdHeader == null) ? null : userIdHeader.trim();
        if (userId == null || userId.isEmpty()) {
            throw new UnauthorizedException("Missing X-User-Id header");
        }

        Set<String> roles = (rolesHeader == null || rolesHeader.trim().isEmpty())
                ? Set.of()
                : Arrays.stream(rolesHeader.split(","))
                .map(String::trim)
                .filter(s -> !s.isEmpty())
                .collect(Collectors.toUnmodifiableSet());

        return new RequestUser(userId, roles);
    }
}

package com.ascendion.aava.workflow.web;

import com.ascendion.aava.workflow.exception.BadRequestException;
import com.ascendion.aava.workflow.exception.ForbiddenException;
import com.ascendion.aava.workflow.exception.NotFoundException;
import com.ascendion.aava.workflow.security.UnauthorizedException;
import jakarta.servlet.http.HttpServletRequest;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.validation.FieldError;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.time.Instant;

/**
 * Maps exceptions to HTTP responses without leaking sensitive info.
 */
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ApiError> handleValidation(MethodArgumentNotValidException ex, HttpServletRequest request) {
        StringBuilder sb = new StringBuilder("Validation failed");
        for (FieldError fe : ex.getBindingResult().getFieldErrors()) {
            sb.append("; ").append(fe.getField()).append(": ").append(fe.getDefaultMessage());
        }
        return error(HttpStatus.BAD_REQUEST, sb.toString(), request);
    }

    @ExceptionHandler(NotFoundException.class)
    public ResponseEntity<ApiError> handleNotFound(NotFoundException ex, HttpServletRequest request) {
        return error(HttpStatus.NOT_FOUND, ex.getMessage(), request);
    }

    @ExceptionHandler(BadRequestException.class)
    public ResponseEntity<ApiError> handleBadRequest(BadRequestException ex, HttpServletRequest request) {
        return error(HttpStatus.BAD_REQUEST, ex.getMessage(), request);
    }

    @ExceptionHandler(ForbiddenException.class)
    public ResponseEntity<ApiError> handleForbidden(ForbiddenException ex, HttpServletRequest request) {
        return error(HttpStatus.FORBIDDEN, ex.getMessage(), request);
    }

    @ExceptionHandler(UnauthorizedException.class)
    public ResponseEntity<ApiError> handleUnauthorized(UnauthorizedException ex, HttpServletRequest request) {
        return error(HttpStatus.UNAUTHORIZED, ex.getMessage(), request);
    }

    private ResponseEntity<ApiError> error(HttpStatus status, String message, HttpServletRequest request) {
        ApiError apiError = new ApiError(Instant.now(), status.value(), status.getReasonPhrase(), message, request.getRequestURI());
        return ResponseEntity.status(status).body(apiError);
    }
}

import com.ascendion.aava.workflow.domain.*;

import org.springframework.transaction.annotation.Transactional;

import java.time.Instant;

/**
 * Append-only audit service.
 */
@Service
public class AuditService {

    private final AuditEntryRepository repo;
    private final Clock clock;

    public AuditService(AuditEntryRepository repo) {
        this.repo = repo;
        this.clock = Clock.systemUTC();
    }

    @Transactional
    public void record(String actor, Artifact artifact, AuditAction action) {
        Instant now = Instant.now(clock);
        repo.save(new AuditEntry(actor, artifact.getId(), artifact.getName(), artifact.getType(), action, now));
    }
}

package com.ascendion.aava.workflow.service;

import com.ascendion.aava.workflow.domain.*;
import com.ascendion.aava.workflow.dto.CreateArtifactRequest;
import com.ascendion.aava.workflow.dto.EditArtifactRequest;
import com.ascendion.aava.workflow.exception.BadRequestException;
import com.ascendion.aava.workflow.exception.ForbiddenException;
import com.ascendion.aava.workflow.exception.NotFoundException;
import com.ascendion.aava.workflow.repo.ArtifactRepository;
import com.ascendion.aava.workflow.repo.ArtifactVersionRepository;
import com.ascendion.aava.workflow.security.RequestUser;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.Clock;
import java.time.Instant;
import java.util.List;

/**
 * Core business logic for draft+approval+versioning.
 */
@Service
public class ArtifactWorkflowService {

    private final ArtifactRepository artifactRepo;
    private final ArtifactVersionRepository versionRepo;
    private final AuditService auditService;
    private final Clock clock;

    public ArtifactWorkflowService(ArtifactRepository artifactRepo, ArtifactVersionRepository versionRepo, AuditService auditService) {
        this.artifactRepo = artifactRepo;
        this.versionRepo = versionRepo;
        this.auditService = auditService;
        this.clock = Clock.systemUTC();
    }

    @Transactional
    public ArtifactVersion createArtifact(CreateArtifactRequest req, RequestUser user) {
        requireAnyRole(user, "ARTIFACT_OWNER", "LEVEL_ADMIN", "SUPER_ADMIN");

        Instant now = Instant.now(clock);
        Artifact artifact = artifactRepo.save(new Artifact(req.name().trim(), req.type(), now));

        ArtifactVersion live = new ArtifactVersion(
                artifact,
                1,
                ArtifactVersionStatus.LIVE,
                req.initialContent(),
                null,
                false,
                true,
                user.userId(),
                now
        );
        ArtifactVersion saved = versionRepo.save(live);

        auditService.record(user.userId(), artifact, AuditAction.PUBLISHED);
        return saved;
    }

    @Transactional
    public ArtifactVersion editArtifact(long artifactId, EditArtifactRequest req, RequestUser user) {
        requireAnyRole(user, "ARTIFACT_OWNER", "LEVEL_ADMIN", "SUPER_ADMIN");

        Artifact artifact = artifactRepo.findById(artifactId)
                .orElseThrow(() -> new NotFoundException("Artifact not found: " + artifactId));

        auditService.record(user.userId(), artifact, AuditAction.EDIT_INITIATED);

        versionRepo.findPendingDraft(artifactId).ifPresent(v -> {
            throw new BadRequestException("A draft is already pending approval for artifactId=" + artifactId);
        });

        int nextVersion = nextVersionNumber(artifactId);
        Instant now = Instant.now(clock);

        ArtifactVersion draft = new ArtifactVersion(
                artifact,
                nextVersion,
                ArtifactVersionStatus.DRAFT,
                req.updatedContent(),
                req.impactAnalysisJson(),
                true,
                false,
                user.userId(),
                now
        );

        ArtifactVersion saved = versionRepo.save(draft);
        auditService.record(user.userId(), artifact, AuditAction.DRAFT_SUBMITTED);

        return saved;
    }

    @Transactional
    public ArtifactVersion acknowledgeImpact(long artifactId, long draftVersionId, boolean acknowledged, RequestUser user) {
        requireAnyRole(user, "APPROVER", "LEVEL_ADMIN", "SUPER_ADMIN");

        ArtifactVersion draft = versionRepo.findById(draftVersionId)
                .orElseThrow(() -> new NotFoundException("Draft version not found: " + draftVersionId));

        if (draft.getArtifact().getId() != artifactId) {
            throw new BadRequestException("Draft does not belong to artifactId=" + artifactId);
        }
        if (!draft.isPendingApproval() || draft.getStatus() != ArtifactVersionStatus.DRAFT) {
            throw new BadRequestException("Version is not a pending DRAFT");
        }

        // Approver must not be the submitter.
        if (draft.getSubmittedBy().equals(user.userId())) {
            throw new ForbiddenException("Submitter cannot acknowledge/approve/reject own submission");
        }

        draft.setImpactAcknowledged(Boolean.TRUE.equals(acknowledged));
        ArtifactVersion saved = versionRepo.save(draft);

        auditService.record(user.userId(), draft.getArtifact(), AuditAction.IMPACT_ACKNOWLEDGED);
        return saved;
    }

    @Transactional
    public ArtifactVersion approve(long artifactId, long draftVersionId, String comment, RequestUser user) {
        return review(artifactId, draftVersionId, comment, user, ApprovalDecision.APPROVED);
    }

    @Transactional
    public ArtifactVersion reject(long artifactId, long draftVersionId, String comment, RequestUser user) {
        return review(artifactId, draftVersionId, comment, user, ApprovalDecision.REJECTED);
    }

    @Transactional(readOnly = true)
    public ArtifactVersion getLiveVersion(long artifactId) {
        return versionRepo.findLiveVersion(artifactId)
                .orElseThrow(() -> new NotFoundException("No LIVE version for artifactId=" + artifactId));
    }

    @Transactional(readOnly = true)
    public List<ArtifactVersion> listVersions(long artifactId) {
        // This list includes all statuses. UI may hide drafts; API returns for governance visibility.
        return versionRepo.findAllVersionsDesc(artifactId);
    }

    @Transactional(readOnly = true)
    public ArtifactVersion getVersion(long artifactId, long versionId) {
        ArtifactVersion v = versionRepo.findById(versionId)
                .orElseThrow(() -> new NotFoundException("Version not found: " + versionId));
        if (v.getArtifact().getId() != artifactId) {
            throw new BadRequestException("Version does not belong to artifactId=" + artifactId);
        }
        return v;
    }

    private ArtifactVersion review(long artifactId, long draftVersionId, String comment, RequestUser user, ApprovalDecision decision) {
        requireAnyRole(user, "APPROVER", "LEVEL_ADMIN", "SUPER_ADMIN");

        if (comment == null || comment.trim().isEmpty()) {
            throw new BadRequestException("Comment is mandatory");
        }

        ArtifactVersion draft = versionRepo.findById(draftVersionId)
                .orElseThrow(() -> new NotFoundException("Draft version not found: " + draftVersionId));

        if (draft.getArtifact().getId() != artifactId) {
            throw new BadRequestException("Draft does not belong to artifactId=" + artifactId);
        }
        if (!draft.isPendingApproval() || draft.getStatus() != ArtifactVersionStatus.DRAFT) {
            throw new BadRequestException("Version is not a pending DRAFT");
        }
        if (draft.getSubmittedBy().equals(user.userId())) {
            throw new ForbiddenException("Submitter cannot approve/reject own submission");
        }
        if (!draft.isImpactAcknowledged()) {
            throw new BadRequestException("Impact analysis must be acknowledged before approve/reject");
        }

        Instant now = Instant.now(clock);
        draft.markReviewed(user.userId(), now, comment.trim());

        if (decision == ApprovalDecision.APPROVED) {
            // Keep artifactId stable; incremented version already assigned.
            // Demote previous LIVE version.
            versionRepo.findLiveVersion(artifactId).ifPresent(live -> {
                live.setStatus(ArtifactVersionStatus.IN_REVIEW);
                versionRepo.save(live);
            });

            draft.setPendingApproval(false);
            draft.setStatus(ArtifactVersionStatus.LIVE);
            ArtifactVersion saved = versionRepo.save(draft);

            auditService.record(user.userId(), saved.getArtifact(), AuditAction.APPROVED);
            auditService.record(user.userId(), saved.getArtifact(), AuditAction.PUBLISHED);
            return saved;
        } else {
            draft.setPendingApproval(false);
            draft.setStatus(ArtifactVersionStatus.REJECTED);
            ArtifactVersion saved = versionRepo.save(draft);

            auditService.record(user.userId(), saved.getArtifact(), AuditAction.REJECTED);
            return saved;
        }
    }

    private int nextVersionNumber(long artifactId) {
        Integer max = versionRepo.findMaxVersionNumber(artifactId);
        return (max == null) ? 1 : (max + 1);
    }

    private static void requireAnyRole(RequestUser user, String... roles) {
        for (String r : roles) {
            if (user.hasRole(r)) {
                return;
            }
        }
        throw new ForbiddenException("Missing required role");
    }
}

package com.ascendion.aava.workflow.web;

import com.ascendion.aava.workflow.domain.ArtifactVersion;
import com.ascendion.aava.workflow.dto.*;
import com.ascendion.aava.workflow.repo.AuditEntryRepository;
import com.ascendion.aava.workflow.security.RequestUser;
import com.ascendion.aava.workflow.security.UserContextResolver;
import com.ascendion.aava.workflow.service.ArtifactWorkflowService;
import jakarta.validation.Valid;
import org.springframework.http.HttpStatus;
import org.springframework.web.bind.annotation.*;

import java.util.List;

/**
 * REST API for artifact workflow.
 */
@RestController
@RequestMapping("/api/artifacts")
public class ArtifactWorkflowController {

    private final ArtifactWorkflowService service;
    private final AuditEntryRepository auditRepo;
    private final UserContextResolver userResolver;

    public ArtifactWorkflowController(ArtifactWorkflowService service, AuditEntryRepository auditRepo, UserContextResolver userResolver) {
        this.service = service;
        this.auditRepo = auditRepo;
        this.userResolver = userResolver;
    }

    private RequestUser user(String userId, String roles) {
        return userResolver.fromHeaders(userId, roles);
    }

    @PostMapping
    @ResponseStatus(HttpStatus.CREATED)
    public ArtifactVersionResponse create(@RequestHeader("X-User-Id") String userId,
                                         @RequestHeader(value = "X-User-Roles", required = false) String roles,
                                         @Valid @RequestBody CreateArtifactRequest req) {
        ArtifactVersion v = service.createArtifact(req, user(userId, roles));
        return toResponse(v);
    }

    @PostMapping("/{artifactId}/edits")
    @ResponseStatus(HttpStatus.CREATED)
    public ArtifactVersionResponse edit(@RequestHeader("X-User-Id") String userId,
                                       @RequestHeader(value = "X-User-Roles", required = false) String roles,
                                       @PathVariable long artifactId,
                                       @Valid @RequestBody EditArtifactRequest req) {
        ArtifactVersion draft = service.editArtifact(artifactId, req, user(userId, roles));
        return toResponse(draft);
    }

    @GetMapping("/{artifactId}/live")
    public ArtifactVersionResponse live(@PathVariable long artifactId) {
        return toResponse(service.getLiveVersion(artifactId));
    }

    @GetMapping("/{artifactId}/versions")
    public List<ArtifactVersionResponse> versions(@PathVariable long artifactId) {
        return service.listVersions(artifactId).stream().map(this::toResponse).toList();
    }

    @GetMapping("/{artifactId}/versions/{versionId}")
    public ArtifactVersionResponse getVersion(@PathVariable long artifactId, @PathVariable long versionId) {
        return toResponse(service.getVersion(artifactId, versionId));
    }

    @PostMapping("/{artifactId}/drafts/{draftVersionId}/impact-ack")
    public ArtifactVersionResponse acknowledgeImpact(@RequestHeader("X-User-Id") String userId,
                                                    @RequestHeader(value = "X-User-Roles", required = false) String roles,
                                                    @PathVariable long artifactId,
                                                    @PathVariable long draftVersionId,
                                                    @Valid @RequestBody AcknowledgeImpactRequest req) {
        ArtifactVersion v = service.acknowledgeImpact(artifactId, draftVersionId, req.acknowledged(), user(userId, roles));
        return toResponse(v);
    }

    @PostMapping("/{artifactId}/drafts/{draftVersionId}/approve")
    public ArtifactVersionResponse approve(@RequestHeader("X-User-Id") String userId,
                                          @RequestHeader(value = "X-User-Roles", required = false) String roles,
                                          @PathVariable long artifactId,
                                          @PathVariable long draftVersionId,
                                          @Valid @RequestBody ReviewDraftRequest req) {
        ArtifactVersion v = service.approve(artifactId, draftVersionId, req.comment(), user(userId, roles));
        return toResponse(v);
    }

    @PostMapping("/{artifactId}/drafts/{draftVersionId}/reject")
    public ArtifactVersionResponse reject(@RequestHeader("X-User-Id") String userId,
                                         @RequestHeader(value = "X-User-Roles", required = false) String roles,
                                         @PathVariable long artifactId,
                                         @PathVariable long draftVersionId,
                                         @Valid @RequestBody ReviewDraftRequest req) {
        ArtifactVersion v = service.reject(artifactId, draftVersionId, req.comment(), user(userId, roles));
        return toResponse(v);
    }

    @GetMapping("/{artifactId}/audit")
    public List<AuditEntryResponse> audit(@PathVariable long artifactId) {
        return auditRepo.findByArtifactIdOrderByTimestampAsc(artifactId)
                .stream()
                .map(a -> new AuditEntryResponse(a.getId(), a.getActor(), a.getArtifactId(), a.getArtifactName(), a.getArtifactType(), a.getAction(), a.getTimestamp()))
                .toList();
    }

    private ArtifactVersionResponse toResponse(ArtifactVersion v) {
        return new ArtifactVersionResponse(
                v.getArtifact().getId(),
                v.getArtifact().getName(),
                v.getArtifact().getType(),
                v.getId(),
                v.getVersionNumber(),
                v.getStatus(),
                v.isPendingApproval(),
                v.isImpactAcknowledged(),
                v.getSubmittedBy(),
                v.getSubmittedAt(),
                v.getImpactAnalysisJson(),
                v.getContent()
        );
    }
}

3. **Code Documentation**

- `Artifact` represents the stable artifact identity (ID never changes).
- `ArtifactVersion` stores versioned content and workflow state:
  - Edits create a new `DRAFT` version with `pendingApproval=true` and `impactAcknowledged=false`.
  - `LIVE` version remains unchanged until approval.
  - Approver must call `impact-ack` before approve/reject; submitter is blocked at API level.
  - Approve sets draft to `LIVE`, demotes previous LIVE to `IN_REVIEW` (so only one LIVE exists), increments version number automatically.
  - Reject sets draft to `REJECTED` and keeps live unchanged.
- `AuditEntry` is append-only and captured via `AuditService` for required actions. No delete/update endpoints are exposed.
- `ArtifactWorkflowController` exposes REST endpoints and enforces validation.
- `GlobalExceptionHandler` provides safe error responses.

**How to run**
- `mvn spring-boot:run`
- Example calls (headers simulate auth):
  - Create: `POST /api/artifacts` with headers `X-User-Id: user-owner`, `X-User-Roles: ARTIFACT_OWNER`
  - Edit (draft): `POST /api/artifacts/1/edits`
  - Acknowledge impact: `POST /api/artifacts/1/drafts/{draftId}/impact-ack` with `X-User-Id: user-approver`, `X-User-Roles: APPROVER`
  - Approve: `POST /api/artifacts/1/drafts/{draftId}/approve` with mandatory JSON `{ "comment": "Reviewed" }`

**Dependencies**
- Spring Boot Web, Validation, Data JPA
- H2 database (runtime)
