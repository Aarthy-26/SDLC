1. **Requirement Summary** — the clarified, confirmed requirement

Build a secure, runnable Java utility that connects to the source database and performs automated profiling/diagnostic scans on 7 tables in the `staging` schema (`mod_record`, `baseline_record`, `impact_record`, `task_record`, `subtask`, `completion_gate`, `audit_event`). It must output a diagnostic report containing, per table/column: total row count, null count and percentage, distinct value count, min/max string length (for text columns), and date ranges (for date/timestamp columns). It must also run orphan foreign key checks for relationships: `subtask.task_record_id -> task_record.id`, `completion_gate.task_record_id -> task_record.id`, and `impact_record.mod_record_id -> mod_record.id`. The report must highlight high-risk issues such as missing mandatory `mod_ref` values, invalid timestamp formats (for string-based timestamp fields), and unmapped sensitivity codes.

**Assumptions** (enterprise-safe defaults used to proceed):
- Java 17.
- Single runnable console app (no Spring) using JDBC.
- Database connection details are provided via environment variables: `DB_URL`, `DB_USER`, `DB_PASSWORD`. No secrets are hardcoded.
- PostgreSQL is the target runtime for the staging schema (consistent with “before transforming data into PostgreSQL”).
- Primary/foreign key column names for orphan checks are defaulted as: `task_record.id`, `mod_record.id`, `subtask.task_record_id`, `completion_gate.task_record_id`, `impact_record.mod_record_id`. If actual column names differ, update the constants in code.
- “Invalid timestamp formats” is checked only for columns of type `text/varchar` whose name contains `time` or `date` and where values do not match ISO-8601 patterns; true typed `timestamp/date` columns are assumed valid by the database.
- “Unmapped sensitivity codes” is checked on columns named `sensitivity_code` or `sensitivity` (case-insensitive) against an allowlist `{PUBLIC, INTERNAL, CONFIDENTIAL, RESTRICTED}`; unknown non-null values are flagged.
- Output report is written to `stdout` and also to a file path provided by `REPORT_PATH` env var (default: `profiling-report.json`).

    private static TableProfile profileTable(Connection connection, DatabaseMetaData metaData, String schema, String table) throws SQLException {
        TableProfile tableProfile = new TableProfile();
        tableProfile.setTable(table);

        long totalRows = queryForLong(connection,
                "SELECT COUNT(*) FROM " + qIdent(schema) + "." + qIdent(table),
                List.of());
        tableProfile.setTotalRows(totalRows);

        Map<String, ColumnInfo> columns = getColumns(metaData, schema, table);

        for (ColumnInfo c : columns.values()) {
            ColumnProfile cp = new ColumnProfile();
            cp.setColumn(c.name());
            cp.setSqlType(c.typeName());
            cp.setNullable(c.nullable());

            // Null metrics
            long nullCount = queryForLong(connection,
                    "SELECT COUNT(*) FROM " + qIdent(schema) + "." + qIdent(table) + " WHERE " + qIdent(c.name()) + " IS NULL",
                    List.of());
            cp.setNullCount(nullCount);
            cp.setNullPercent(totalRows == 0 ? 0.0 : (nullCount * 100.0 / totalRows));

            // Distinct values (safe default: use COUNT(DISTINCT col))
            long distinctCount = queryForLong(connection,
                    "SELECT COUNT(DISTINCT " + qIdent(c.name()) + ") FROM " + qIdent(schema) + "." + qIdent(table),
                    List.of());
            cp.setDistinctCount(distinctCount);

            // String length metrics for text-like columns
            if (isTextType(c.typeName())) {
                MinMaxLong minMax = queryForMinMaxLong(connection,
                        "SELECT MIN(LENGTH(" + qIdent(c.name()) + ")), MAX(LENGTH(" + qIdent(c.name()) + ")) FROM " + qIdent(schema) + "." + qIdent(table) + " WHERE " + qIdent(c.name()) + " IS NOT NULL",
                        List.of());
                cp.setMinStringLength(minMax.min());
                cp.setMaxStringLength(minMax.max());
            }

            // Date ranges for date/time columns
            if (isDateTimeType(c.typeName())) {
                MinMaxString minMax = queryForMinMaxString(connection,
                        "SELECT MIN(" + qIdent(c.name()) + ")::text, MAX(" + qIdent(c.name()) + ")::text FROM " + qIdent(schema) + "." + qIdent(table) + " WHERE " + qIdent(c.name()) + " IS NOT NULL",
                        List.of());
                cp.setMinDateValue(minMax.min());
                cp.setMaxDateValue(minMax.max());
            }

            tableProfile.getColumns().add(cp);
        }

        // Basic table-level anomalies (example): empty table
        if (totalRows == 0) {
            tableProfile.getNotes().add("Table has zero rows.");
        }

        return tableProfile;
    }

    private static Map<String, ColumnInfo> getColumns(DatabaseMetaData metaData, String schema, String table) throws SQLException {
        Map<String, ColumnInfo> cols = new LinkedHashMap<>();
        try (ResultSet rs = metaData.getColumns(null, schema, table, null)) {
            while (rs.next()) {
                String colName = rs.getString("COLUMN_NAME");
                String typeName = rs.getString("TYPE_NAME");
                int nullable = rs.getInt("NULLABLE");
                boolean isNullable = nullable == DatabaseMetaData.columnNullable;
                cols.put(colName, new ColumnInfo(colName, typeName, isNullable));
            }
        }
        return cols;
    }

    private static OrphanCheckResult runOrphanCheck(Connection connection, String schema, OrphanCheck check) throws SQLException {
        // Count child rows where fk is not null and no matching parent exists.
        String sql = "SELECT COUNT(*) " +
                "FROM " + qIdent(schema) + "." + qIdent(check.childTable()) + " c " +
                "LEFT JOIN " + qIdent(schema) + "." + qIdent(check.parentTable()) + " p " +
                "ON c." + qIdent(check.childFkColumn()) + " = p." + qIdent(check.parentPkColumn()) + " " +
                "WHERE c." + qIdent(check.childFkColumn()) + " IS NOT NULL AND p." + qIdent(check.parentPkColumn()) + " IS NULL";

        long orphanCount = queryForLong(connection, sql, List.of());

        OrphanCheckResult result = new OrphanCheckResult();
        result.setRelationship(check.relationshipName());
        result.setChildTable(check.childTable());
        result.setChildFkColumn(check.childFkColumn());
        result.setParentTable(check.parentTable());
        result.setParentPkColumn(check.parentPkColumn());
        result.setOrphanCount(orphanCount);
        result.setRisk(orphanCount > 0 ? "HIGH" : "LOW");
        return result;
    }

    private static List<DiagnosticFinding> runDiagnostics(Connection connection, String schema) throws SQLException {
        List<DiagnosticFinding> findings = new ArrayList<>();

        // Missing mandatory mod_ref (assumed column exists on mod_record)
        if (columnExists(connection, schema, "mod_record", "mod_ref")) {
            long missingModRef = queryForLong(connection,
                    "SELECT COUNT(*) FROM " + qIdent(schema) + "." + qIdent("mod_record") +
                            " WHERE mod_ref IS NULL OR BTRIM(mod_ref) = ''",
                    List.of());
            if (missingModRef > 0) {
                findings.add(DiagnosticFinding.high("mod_record.mod_ref", "Missing mandatory mod_ref values: " + missingModRef));
            }
        } else {
            findings.add(DiagnosticFinding.medium("mod_record.mod_ref", "Column mod_ref not found; mandatory check skipped (update column name mapping if needed)."));
        }

        // Unmapped sensitivity codes across all tables for columns named sensitivity/sensitivity_code
        for (String table : TABLES) {
            Optional<String> sensitivityColumn = findSensitivityColumn(connection, schema, table);
            if (sensitivityColumn.isPresent()) {
                String col = sensitivityColumn.get();
                List<String> invalid = queryForStringList(connection,
                        "SELECT DISTINCT " + qIdent(col) + " FROM " + qIdent(schema) + "." + qIdent(table) +
                                " WHERE " + qIdent(col) + " IS NOT NULL",
                        List.of());

                long unmappedCount = invalid.stream()
                        .filter(Objects::nonNull)
                        .map(String::trim)
                        .filter(s -> !s.isEmpty())
                        .filter(s -> !SENSITIVITY_ALLOWLIST.contains(s.toUpperCase(Locale.ROOT)))
                        .count();

                if (unmappedCount > 0) {
                    findings.add(DiagnosticFinding.high(table + "." + col,
                            "Unmapped sensitivity codes detected (non-allowlisted distinct values): " + unmappedCount +
                                    ". Allowlist=" + SENSITIVITY_ALLOWLIST));
                }
            }
        }

        // Invalid timestamp formats for text/varchar columns whose name suggests date/time
        for (String table : TABLES) {
            Map<String, String> textDateCols = findTextDateLikeColumns(connection, schema, table);
            for (Map.Entry<String, String> e : textDateCols.entrySet()) {
                String col = e.getKey();
                // Pull a bounded sample of distinct values (avoid huge scans). Then count invalid in that sample.
                // For full accuracy, replace with a server-side regex count if desired.
                List<String> sample = queryForStringList(connection,
                        "SELECT DISTINCT " + qIdent(col) + " FROM " + qIdent(schema) + "." + qIdent(table) +
                                " WHERE " + qIdent(col) + " IS NOT NULL LIMIT 5000",
                        List.of());

                long invalidCount = sample.stream()
                        .filter(Objects::nonNull)
                        .map(String::trim)
                        .filter(s -> !s.isEmpty())
                        .filter(v -> !isValidTimestampString(v))
                        .count();

                if (invalidCount > 0) {
                    findings.add(DiagnosticFinding.high(table + "." + col,
                            "Invalid timestamp-like strings detected in sample distinct values: " + invalidCount +
                                    " (sampled up to 5000 distinct non-null values)."));
                }
            }
        }

        return findings;
    }

    private static Optional<String> findSensitivityColumn(Connection connection, String schema, String table) throws SQLException {
        Set<String> candidates = Set.of("sensitivity_code", "sensitivity");
        try (PreparedStatement ps = connection.prepareStatement(
                "SELECT column_name FROM information_schema.columns WHERE table_schema = ? AND table_name = ?")) {
            ps.setString(1, schema);
            ps.setString(2, table);
            try (ResultSet rs = ps.executeQuery()) {
                while (rs.next()) {
                    String name = rs.getString(1);
                    if (name == null) {
                        continue;
                    }
                    if (candidates.contains(name.toLowerCase(Locale.ROOT))) {
                        return Optional.of(name);
                    }
                }
            }
        }
        return Optional.empty();
    }

    private static Map<String, String> findTextDateLikeColumns(Connection connection, String schema, String table) throws SQLException {
        Map<String, String> cols = new LinkedHashMap<>();
        try (PreparedStatement ps = connection.prepareStatement(
                "SELECT column_name, data_type FROM information_schema.columns WHERE table_schema = ? AND table_name = ?")) {
            ps.setString(1, schema);
            ps.setString(2, table);
            try (ResultSet rs = ps.executeQuery()) {
                while (rs.next()) {
                    String col = rs.getString(1);
                    String dataType = rs.getString(2);
                    if (col == null || dataType == null) {
                        continue;
                    }
                    String colLower = col.toLowerCase(Locale.ROOT);
                    if ((colLower.contains("time") || colLower.contains("date"))
                            && (dataType.equalsIgnoreCase("character varying")
                            || dataType.equalsIgnoreCase("text")
                            || dataType.equalsIgnoreCase("character"))) {
                        cols.put(col, dataType);
                    }
                }
            }
        }
        return cols;
    }

    private static boolean isTextType(String typeName) {
        if (typeName == null) {
            return false;
        }
        String t = typeName.toLowerCase(Locale.ROOT);
        return t.contains("char") || t.contains("text") || t.contains("varchar");
    }

    private static boolean isDateTimeType(String typeName) {
        if (typeName == null) {
            return false;
        }
        String t = typeName.toLowerCase(Locale.ROOT);
        return t.contains("timestamp") || t.equals("date") || t.contains("time");
    }

    private static boolean isValidTimestampString(String value) {
        String v = value.trim();
        if (v.isEmpty()) {
            return true;
        }
        if (ISO_INSTANT.matcher(v).matches()) {
            try {
                Instant.parse(v);
                return true;
            } catch (DateTimeParseException ignored) {
                return false;
            }
        }
        if (ISO_OFFSET.matcher(v).matches()) {
            try {
                OffsetDateTime.parse(v, DateTimeFormatter.ISO_OFFSET_DATE_TIME);
                return true;
            } catch (DateTimeParseException ignored) {
                return false;
            }
        }
        if (ISO_LOCAL_DATE_TIME.matcher(v).matches()) {
            // Parse without offset.
            try {
                // Accept either 'T' or space separator.
                String normalized = v.replace(' ', 'T');
                java.time.LocalDateTime.parse(normalized, DateTimeFormatter.ISO_LOCAL_DATE_TIME);
                return true;
            } catch (DateTimeParseException ignored) {
                return false;
            }
        }
        return false;
    }

    private static long queryForLong(Connection connection, String sql, List<Object> params) throws SQLException {
        Objects.requireNonNull(connection, "connection");
        Objects.requireNonNull(sql, "sql");
        try (PreparedStatement ps = connection.prepareStatement(sql)) {
            for (int i = 0; i < params.size(); i++) {
                ps.setObject(i + 1, params.get(i));
            }
            try (ResultSet rs = ps.executeQuery()) {
                if (rs.next()) {
                    return rs.getLong(1);
                }
                return 0L;
            }
        }
    }

    private static String qIdent(String identifier) {

    private static String toPrettyJson(Object obj) {
        ObjectMapper mapper = new ObjectMapper();
        mapper.registerModule(new JavaTimeModule());
        mapper.disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS);
        mapper.setSerializationInclusion(JsonInclude.Include.NON_NULL);
        try {
            return mapper.writerWithDefaultPrettyPrinter().writeValueAsString(obj);
        } catch (JsonProcessingException e) {
            throw new IllegalStateException("Failed to serialize report to JSON", e);
        }
    }

    private static void writeFileAtomically(Path path, String content) throws IOException {
        Objects.requireNonNull(path, "path");
        Objects.requireNonNull(content, "content");

        Path parent = path.toAbsolutePath().getParent();
        if (parent != null) {
            Files.createDirectories(parent);
        }
        Path tmp = path.toAbsolutePath().resolveSibling(path.getFileName().toString() + ".tmp");
        Files.writeString(tmp, content, StandardCharsets.UTF_8);
        Files.move(tmp, path, java.nio.file.StandardCopyOption.REPLACE_EXISTING, java.nio.file.StandardCopyOption.ATOMIC_MOVE);
    }

3. **Code Documentation** — classes/methods/logic explanation + dependencies

- `ProfilingApp` (main): reads DB configuration from environment variables, connects using JDBC in read-only mode, runs table profiling, orphan checks, and diagnostics, then writes a JSON report to stdout and `REPORT_PATH`.
- `profileTable(...)`: for each table, computes total row count and for each column computes null count/%, distinct count, min/max string length (text columns), and min/max date values (date/timestamp columns).
- `runOrphanCheck(...)`: left-joins child to parent and counts orphan rows (FK present but no parent match). Risk is `HIGH` if orphanCount > 0.
- `runDiagnostics(...)`: flags (1) missing `mod_ref` values, (2) unmapped sensitivity codes, (3) invalid timestamp-like strings for date/time-named text columns using ISO-8601 checks.
- DTOs: `ProfilingReport`, `TableProfile`, `ColumnProfile`, `OrphanCheckResult`, `DiagnosticFinding` are all defined in the same file to keep compilation straightforward.
