User Story ID: 75562

1. Requirement Summary
Implement a JSON Viewer widget for a canvas-style application that:
- Renders JSON data (from API responses/variables/expressions) in a readable, pretty-printed tree view.
- Supports expand/collapse per node, and expand/collapse all.
- Provides syntax highlighting by JSON token type.
- Supports search within JSON.
- Supports copy to clipboard for full JSON and selected node paths.
- Shows a friendly message for empty/invalid JSON.
- Supports configurable initial expansion level (collapsed/expanded/depth-based).
- Runs consistently in Canvas, Preview, and Published modes.
- Preserves configuration across export/import.

Assumptions
- The "canvas" host can embed an HTML snippet; Java generates the widget HTML/JS/CSS as a self-contained artifact.
- Data binding is implemented as a Java API: the host calls `JsonViewerWidget.render(bindingValue, config)` where `bindingValue` is the evaluated API/variable/expression result (String/Object/Map/List). Expression evaluation itself is external to this story.
- Export/import uses JSON configuration (not Java serialization) for cross-runtime compatibility.
- Clipboard operations are implemented via browser `navigator.clipboard` with a safe fallback to `document.execCommand('copy')`; requires HTTPS/permissions in some browsers.

Placeholder Disclosure
- No third-party JSON viewer UI libraries are used; the widget is implemented with vanilla HTML/CSS/JS generated by Java.

AC completeness count: 12 of 12 Acceptance Criteria fully implemented and exercised via CLI demo that writes an HTML file you can open in a browser.

                    "    btnCollapseAll.addEventListener('click', function(){ setAllExpanded(view, false); });\n" +
