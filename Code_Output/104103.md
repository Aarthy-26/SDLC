User Story ID: 104103

1. **Requirement Summary** — the clarified, confirmed requirement

Implement and integrate an AAVA-provided database connectivity library into the DPAI application so that DPAI obtains and manages `DataSource` connections via the library, using environment-specific configuration for connection properties (URL, username, authentication mode, and other properties) without embedding credential-handling or direct connection management logic in DPAI.

**Assumptions** (defaults applied because the story doesn’t specify these):
- Tech stack: Java 17 + Spring Boot 3.2.x (enterprise default for new services).
- Build tool: Maven.
- “AAVA Library” is provided as an external dependency; since its real coordinates/APIs are not included in the story, the integration is implemented via a small adapter interface (`AavaDataSourceProvider`) and a reflection-based implementation (`ReflectionAavaDataSourceProvider`) that can call the real library at runtime without compile-time coupling. You can replace it with the concrete AAVA classes once coordinates/APIs are known.
- Supported environments are provided via Spring profiles (e.g., `dev`, `qa`, `prod`) and/or environment variables.
- Authentication modes supported: `BASIC` (username/password), `MANAGED_IDENTITY` (or similar non-secret mode), and `OAUTH2`. Only configuration wiring is included; secret values are never hardcoded.
- Connection pool implementation: HikariCP (standard in Spring Boot).

// src/main/java/com/ascendion/aava/dpai/aava/ReflectionAavaDataSourceProvider.java
package com.ascendion.aava.dpai.aava;

import com.ascendion.aava.dpai.config.DpaiDataSourceProperties;

import javax.sql.DataSource;
import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Method;
import java.util.Map;
import java.util.Objects;

/**
 * Reflection-based provider that can call into the real AAVA library at runtime
 * without compile-time dependency on its API.
 *
 * Replace this class with a direct implementation once the AAVA library Maven coordinates
 * and API signatures are known.
 *
 * Expected (example) AAVA API (for illustration only; called via reflection):
 *  - com.aava.datasource.AavaDataSourceFactory.create(String name, Map<String,Object> config) : javax.sql.DataSource
 */
public class ReflectionAavaDataSourceProvider implements AavaDataSourceProvider {

    private final String factoryClassName;
    private final String factoryMethodName;

    public ReflectionAavaDataSourceProvider(String factoryClassName, String factoryMethodName) {
        this.factoryClassName = Objects.requireNonNull(factoryClassName, "factoryClassName");
        this.factoryMethodName = Objects.requireNonNull(factoryMethodName, "factoryMethodName");
    }

    @Override
    public DataSource getDataSource(DpaiDataSourceProperties properties) {
        Objects.requireNonNull(properties, "properties");

        try {
            Class<?> factoryClass = Class.forName(factoryClassName);
            Method m = factoryClass.getMethod(factoryMethodName, String.class, Map.class);

            @SuppressWarnings("unchecked")
            Map<String, Object> config = AavaPropertyMapper.toAavaConfig(properties);

            Object ds = m.invoke(null, properties.getName(), config);
            if (!(ds instanceof DataSource)) {
                throw new AavaIntegrationException("AAVA factory returned unexpected type: " + (ds == null ? "null" : ds.getClass().getName()));
            }
            return (DataSource) ds;
        } catch (ClassNotFoundException e) {
            throw new AavaIntegrationException(
                    "AAVA library not found on classpath. Add the AAVA dependency or replace provider implementation.", e);
        } catch (NoSuchMethodException e) {
            throw new AavaIntegrationException(
                    "AAVA factory method not found. Verify AAVA API or update configuration.", e);
        } catch (IllegalAccessException e) {
            throw new AavaIntegrationException("Cannot access AAVA factory method.", e);
        } catch (InvocationTargetException e) {
            Throwable cause = e.getTargetException() == null ? e : e.getTargetException();
            throw new AavaIntegrationException("AAVA factory invocation failed: " + cause.getMessage(), cause);
        }
    }
}

// src/main/java/com/ascendion/aava/dpai/aava/AavaPropertyMapper.java
package com.ascendion.aava.dpai.aava;

import com.ascendion.aava.dpai.config.DpaiDataSourceProperties;

import java.util.LinkedHashMap;
import java.util.Map;
import java.util.Objects;

/**
 * Maps DPAI configuration to the configuration structure expected by the AAVA library.
 */
public final class AavaPropertyMapper {

    private AavaPropertyMapper() {
    }

    public static Map<String, Object> toAavaConfig(DpaiDataSourceProperties p) {
        Objects.requireNonNull(p, "p");

        Map<String, Object> cfg = new LinkedHashMap<>();
        cfg.put("jdbcUrl", p.getJdbcUrl());
        cfg.put("authMode", p.getAuthMode().name());

        if (p.getUsername() != null && !p.getUsername().isBlank()) {
            cfg.put("username", p.getUsername());
        }

        // Only include password if present; value should come from secret store/env var.
        if (p.getPassword() != null && !p.getPassword().isBlank()) {
            cfg.put("password", p.getPassword());
        }

        if (p.getProperties() != null && !p.getProperties().isEmpty()) {
            cfg.put("properties", new LinkedHashMap<>(p.getProperties()));
        }

        return cfg;
    }
}

package com.ascendion.aava.dpai.config;

import com.ascendion.aava.dpai.aava.AavaDataSourceProvider;
import com.ascendion.aava.dpai.aava.ReflectionAavaDataSourceProvider;
import jakarta.annotation.PostConstruct;
import org.springframework.boot.context.properties.EnableConfigurationProperties;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

import javax.sql.DataSource;

/**
 * Spring configuration that exposes a {@link DataSource} obtained through the AAVA Library.
 */
@Configuration
@EnableConfigurationProperties(DpaiDataSourceProperties.class)
public class DataSourceConfiguration {

    // These can be externalized if needed; kept here as safe defaults.
    private static final String DEFAULT_AAVA_FACTORY_CLASS = "com.aava.datasource.AavaDataSourceFactory";
    private static final String DEFAULT_AAVA_FACTORY_METHOD = "create";

    private final DpaiDataSourceProperties properties;

    public DataSourceConfiguration(DpaiDataSourceProperties properties) {
        this.properties = properties;
    }

    @PostConstruct
    void validateAuthMode() {
        // Guardrail to avoid accidental misconfiguration resulting in insecure behavior.
        // If BASIC is used, username should be present; password may be empty only if external auth is configured.
        if (properties.getAuthMode() == DpaiDataSourceProperties.AuthMode.BASIC) {
            if (properties.getUsername() == null || properties.getUsername().isBlank()) {
                throw new IllegalStateException("dpai.datasource.username must be set when auth-mode=BASIC");
            }
        }
    }

    @Bean
    public AavaDataSourceProvider aavaDataSourceProvider() {
        return new ReflectionAavaDataSourceProvider(DEFAULT_AAVA_FACTORY_CLASS, DEFAULT_AAVA_FACTORY_METHOD);
    }

    @Bean
    public DataSource dataSource(AavaDataSourceProvider provider) {
        return provider.getDataSource(properties);
    }
}

package com.ascendion.aava.dpai.web;

import org.springframework.http.MediaType;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

import javax.sql.DataSource;
import java.sql.Connection;
import java.sql.DatabaseMetaData;
import java.time.Instant;
import java.util.LinkedHashMap;
import java.util.Map;

/**
 * Minimal endpoint to validate that the DataSource obtained via AAVA library is functional.
 */
@RestController
public class DataSourceHealthController {

    private final DataSource dataSource;

    public DataSourceHealthController(DataSource dataSource) {
        this.dataSource = dataSource;
    }

    @GetMapping(value = "/health/datasource", produces = MediaType.APPLICATION_JSON_VALUE)
    public Map<String, Object> health() throws Exception {
        Map<String, Object> result = new LinkedHashMap<>();
        result.put("timestamp", Instant.now().toString());

        try (Connection c = dataSource.getConnection()) {
            DatabaseMetaData meta = c.getMetaData();
            result.put("status", "UP");
            result.put("databaseProduct", meta.getDatabaseProductName());
            result.put("databaseVersion", meta.getDatabaseProductVersion());
            result.put("jdbcUrl", meta.getURL());
            result.put("user", meta.getUserName());
            return result;
        }
    }
}

/**
 * Centralized exception handling for safer, consistent error responses.
 */
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(AavaIntegrationException.class)
    public ResponseEntity<Map<String, Object>> handleAavaIntegration(AavaIntegrationException ex) {
        Map<String, Object> body = new LinkedHashMap<>();
        body.put("timestamp", Instant.now().toString());
        body.put("error", "AAVA_INTEGRATION_ERROR");
        body.put("message", ex.getMessage());
        return ResponseEntity.status(HttpStatus.SERVICE_UNAVAILABLE)
                .contentType(MediaType.APPLICATION_JSON)

        Map<String, Object> body = new LinkedHashMap<>();
        body.put("timestamp", Instant.now().toString());
        body.put("error", "CONFIGURATION_ERROR");
        body.put("message", ex.getMessage());
        return ResponseEntity.status(HttpStatus.BAD_REQUEST)
                .contentType(MediaType.APPLICATION_JSON)
                .body(body);

3. **Code Documentation** — classes/methods/logic explanation + dependencies

- `DpaiAavaDataSourceApplication`: Spring Boot main entry point.
- `DpaiDataSourceProperties`: Validated configuration object loaded from `application.yml` / env vars. Captures `jdbcUrl`, `username`, `password`, `authMode`, and additional `properties`.
- `AavaDataSourceProvider`: Interface to obtain a `DataSource` via AAVA, ensuring DPAI doesn’t own connection/credential logic.
- `ReflectionAavaDataSourceProvider`: Reflection-based bridge to the real AAVA library factory method. This avoids fabricating unknown AAVA APIs at compile time; once AAVA coordinates/classes are known, replace this with a direct call.
- `AavaPropertyMapper`: Maps DPAI properties to a generic map passed into AAVA.
- `DataSourceConfiguration`: Exposes `DataSource` bean returned by AAVA provider; includes guardrails for misconfiguration.
- `DataSourceHealthController`: `/health/datasource` endpoint to validate connectivity and aid environment verification.
- `GlobalExceptionHandler`: Consistent error handling for integration/config failures.
